🖥️ Installer la version Windows

Un seul fichier .exe autonome — aucune installation de .NET requise.

📦
LogTail.exe
Windows 10 / 11 · 64 bits · ~80 MB
⬇ Télécharger
  1. Cliquez sur Télécharger ci-dessus
  2. Si Windows affiche SmartScreen → Informations complémentaires puis Exécuter quand même
  3. L'application s'ouvre directement — aucune installation
  4. Cliquez Ouvrir ou glissez votre fichier .log dans la fenêtre

📱 Version Multi-plateforme (MAUI)

.NET MAUI permet d'avoir une seule base de code sur Windows, macOS, Android et iOS.

  1. Windows — application de bureau native
  2. macOS — application Mac native
  3. Android — application mobile (.apk)
  4. iOS / iPadOS — application Apple

Cette version est en cours de développement.
